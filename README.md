## 🛣️ Roadway Vision Projects

work i've been doing around extracting structured features from road and street-level imagery — useful for mapping, autonomous driving research, and urban accessibility analysis.

**[lane-feature-extractor](https://github.com/Bilalgpt/lane-feature-extractor)** — encoder-decoder network for instance-level lane detection from dashcam footage. outputs per-lane masks with confidence scores, includes batch inference and CLAHE preprocessing for low-light conditions. trained on TuSimple.

**[roadway-segmentation-pipeline](https://github.com/Bilalgpt/roadway-segmentation-pipeline)** — semantic segmentation pipeline for road-level features: road surface, sidewalks, lane markings, curbs, crosswalks. fine-tuned ResNet34/UNet on KITTI + Cityscapes. full training and inference scripts included.

**[sidewalk-crack-detector](https://github.com/Bilalgpt/sidewalk-crack-detector)** — CNN classifier for detecting surface cracks and defects on sidewalk pavement from street photos. tiles images into patches, scores each patch, and outputs annotated bounding boxes. built for pedestrian accessibility mapping work.
